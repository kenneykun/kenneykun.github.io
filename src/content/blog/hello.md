这是这个博客的第一篇。与其写一篇“欢迎来到我的博客”的模板文，不如把它的构造过程记下来——以后想改的时候，省得重新摸索。

## 它是怎么搭的

完全静态：没有数据库、没有后台、没有服务器进程。三块拼起来就是全部：

1. **Astro** 把 `src/` 里的页面和 Markdown 编译成纯 HTML；
2. **Markdown 文件**就是文章，frontmatter 里写标题和日期；
3. **任意静态托管**（Cloudflare Pages、EdgeOne Pages、GitHub Pages）负责把它发到网上。

写完一篇文章，`git push`，一分钟内线上就更新了。这就是全部工作流。

## 写一篇新文章

在 `src/content/blog/` 下新建一个 `.md` 文件，文件名就是 URL：

```md
---
title: '一篇文章的标题'
description: '出现在列表和搜索结果里的一句话摘要'
pubDate: 2026-11-02
tags: ['Godot']
---

正文从这里开始，正常写 Markdown 就行。
```

支持的 Markdown 语法基本不用记，常用的都能写：

- **加粗**、*斜体*、`行内代码`
- [链接](https://astro.build)、图片、引用、表格
- 代码块（带语法高亮）

> 引用块长这样。适合放一句摘抄，或者一句只有自己看得懂的备注。

| 元素 | 说明 |
| --- | --- |
| frontmatter | 决定标题、日期、标签和是否草稿 |
| 文件名 | 决定文章 URL |
| 正文 | 纯 Markdown |

## 接下来写什么

大概三类：

- **开发日志**：这款游戏每周改了什么，配截图；
- **技术笔记**：Godot 里踩过的坑，写下来免得再踩；
- **读完的东西**：书、文章、游戏，值得记一笔的。

写给别人看是次要的，主要是写给三个月后的自己。
